مكتبة الكوثر — متجر + خدمة طباعة (لوحة تحكم أونلاين)
=====================================================
الملفات:
- index.html     صفحة الموقع للزبائن (منتجات + طباعة وتصوير)
- admin.html     لوحة التحكم على الرابط /admin
- api/ و lib/    الخادم (المنتجات، الإعدادات، رفع ملفات الطباعة، التنظيف اليومي)
- products.js    قائمة أولية فارغة (المنتجات تُضاف من اللوحة)
- img/logo.png   لوجو مؤقت (استبدليه من اللوحة أو بملف بنفس الاسم)
- package.json, vercel.json  إعدادات Vercel

الإعداد (مرة واحدة):
1) ارفعي المجلد على مستودع GitHub جديد، ثم في Vercel: Add New > Project واختاري المستودع > Deploy.
2) في المشروع: Storage > Create > Blob، Access = Public، وعلّمي «Add a read-write token env var»، ثم Connect.
3) Settings > Environment Variables: أضيفي ADMIN_PASSWORD بكلمة مرور قوية (Production).
4) Deployments > Redeploy.
5) افتحي /admin وادخلي مرة واحدة (يجهّز التخزين).
6) مهم: افتحي index.html على GitHub وبدّلي YOUR-SITE.vercel.app (4 مرات في أول الملف) برابط موقعك الحقيقي،
   عشان صورة ومعاينة الرابط تظهر في واتساب.

الاستخدام:
- المنتجات: الاسم، الكود، السعر، الخصم (نسبة أو مبلغ)، الألوان، الصور (ترتيب وحذف)، الوصف.
- الخصم: يظهر السعر قبل الخصم مشطوبًا والسعر بعده، وشارة «خصم %».
- إعدادات الموقع: الاسم، اللوجو، اللون، الإعلان، أرقام الهاتف والواتساب، فيسبوك، الأقسام، الشارات، الفروع.
- الطباعة: تفعيل/إخفاء التبويب، ملاحظة بالأسعار، ومدة حذف ملفات الطباعة (افتراضي 7 أيام).

طباعة المستندات:
- الزبون يرفع حتى 5 ملفات (PDF/Word/PowerPoint/Excel/صور، حتى 3 ميجا للملف). الصور بتتصغر تلقائيًا.
- الملف الأكبر من 3 ميجا بيتبعت يدويًا في محادثة واتساب.
- الطلب يوصل على واتساب برسالة فيها طريقة الطباعة وعدد النسخ وروابط الملفات والملاحظات.
- الملفات تُحذف تلقائيًا بعد المدة المحددة (مرة يوميًا)، أو من زر «حذف ملفات الطباعة القديمة الآن».
